Platform

Everything a modern frontend needs

Opinionated defaults, sensible knobs. Nothing to provision, nothing to patch.

Global anycast network

Requests land at the nearest point of presence automatically. No regions to pick, no failover scripts to write.

TLS that renews itself

Certificates are issued, rotated and stapled for you. HTTP is redirected to HTTPS from the first request onward.

Instant invalidation

Purge a path or the whole tree in seconds. Cache keys are versioned per deploy so rollbacks are atomic.

Edge firewall

Rate limiting, bot scoring and geo rules evaluated before a request ever reaches your origin.

Real-user metrics

Core Web Vitals, cache hit ratio and origin latency broken down by country, device and release.

Functions at the edge

Rewrite URLs, sign cookies or run A/B splits in a few lines of JavaScript, executed next to the viewer.

How it works

Three steps from folder to global

The whole pipeline is a single command — or a push to your default branch.

01 · Connect an origin

Point us at an object store, a bucket or your own server. Private origins stay private — only the network can read them.

02 · Attach your domain

Add the hostname, drop one alias record in DNS and the certificate is provisioned before propagation finishes.

03 · Ship

Every deploy is immutable and instantly reversible. Preview URLs come free with each pull request.
